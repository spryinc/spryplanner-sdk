# Changelog

## 0.1.0-alpha.1

First private distribution candidate: compiled ESM/CommonJS and declarations,
canonical personal-task models, scoped-key transport, explicit prepared-command
recovery, version preconditions, query pagination and operation lookup. Public
registry publication and deployed release acceptance remain pending.

Release preparation: verified the @spryinc organization and adopted public
package identity @spryinc/spryplanner-sdk. Adopted Apache-2.0 with bundled MIT
notices, added npm/pnpm external qualification and a protected OIDC alpha release
workflow. Public source, production-auth acceptance and release activation remain
pending; no registry release has occurred.
